Cherry Chat app-trusted token only, zero-signature, no wallet
authMode: app-trusted
The host backend is the sole source of trust. It mints a token asserting the user's wallet address and Cherry accepts it — no wallet connect, no signature, no wallet popup anywhere in this flow. This mode is not self-serve: it is assigned by Cherry admins on request. See README.md.
