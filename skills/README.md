# Cherry Embed SDK Skills

AI-powered integration assistant for `@cherrydotfun/chat-embed-sdk`.

## Available Skills

### `cherry-embed-integration`

Guides you through embedding a Cherry Chat public room into an existing web3 Solana application (web, React Native, or Flutter) with wallet-based authentication.

The skill:
1. Detects the platform (web / React Native / Flutter) and follows exactly one integration path
2. Creates a backend token endpoint when using `app-trusted+wallet` auth
3. Mounts the chat widget with custom theming (web), or wires the WebView host page + native signing bridge (React Native / Flutter)
4. Sets up event handling
5. Verifies the integration end-to-end

It pairs with the platform-adaptive setup prompt generated by the embed editor at [portal.cherry.fun](https://portal.cherry.fun) (same detection step, same two paths): paste the prompt for your exact embed config, and the skill supplies the deeper reference material.

## Installation

### Claude Code

```bash
# Copy skill to global skills directory
cp -r node_modules/@cherrydotfun/chat-embed-sdk/skills/cherry-embed-integration ~/.claude/skills/

# Or symlink (updates with package)
ln -s $(pwd)/node_modules/@cherrydotfun/chat-embed-sdk/skills/cherry-embed-integration ~/.claude/skills/cherry-embed-integration
```

### Codex

```bash
cp -r node_modules/@cherrydotfun/chat-embed-sdk/skills/cherry-embed-integration ~/.agents/skills/
```

### Project-Level (CLAUDE.md)

Add to your project's `CLAUDE.md`:

```markdown
## Skills

- Cherry Embed Integration: `node_modules/@cherrydotfun/chat-embed-sdk/skills/cherry-embed-integration/SKILL.md`
```

## Usage

In Claude Code or Codex, say:

> "Add Cherry Chat embed to this project"

or

> "Integrate @cherrydotfun/chat-embed-sdk"

The skill will activate and guide you through each step.
